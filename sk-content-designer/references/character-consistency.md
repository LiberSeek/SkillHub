# Character Consistency

这份约束用于个人 IP 和角色图生成。

## 先锁什么

每次出图都先锁 4 类锚点：

1. 脸部锚点
2. 气质锚点
3. 道具锚点
4. taboo drift

## 脸部锚点

至少明确：

- 发型长度和方向
- 眼镜样式
- 眉毛浓度
- 下颌线感受
- 肤色范围

## 气质锚点

至少明确：

- 更偏温柔还是锐利
- 更偏理想主义还是现实主义
- 更偏少年感还是成熟感
- 是否保留轻微书卷气

## 道具锚点

道具只服务身份，不要喧宾夺主。

例如：

- 宇航员：头盔、星图、航天舱
- 钢琴家：钢琴、乐谱、舞台灯
- 侠客：长剑、斗笠、风沙、夜路

## taboo drift

以下情况默认要避免：

- 脸型忽胖忽瘦
- 眼镜经常变化
- 五官比例漂移太大
- 人物年龄感突然变化
- 同一系列里时而写实时而卡通，但没有明确意图

## 最佳实践

- 先产 2 到 4 张定妆图
- 选 1 张作为“母版锚点图”
- 后续所有 archetype 都回看这张母版
- 提示词里优先写稳定特征，再写身份和场景

## 失败时怎么修

如果人物不稳定，不要继续加场景复杂度。

优先回退到：

1. 更干净背景
2. 更少道具
3. 更强人物正面信息
4. 更少风格形容词
