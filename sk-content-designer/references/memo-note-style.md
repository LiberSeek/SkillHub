# Memo Note Style

这条路线用于：

- 备忘录风图文
- 摘录卡
- 公众号长图里的单页摘录
- 财经 / 行业观察里的“结论页”“拆解页”

## 什么时候优先用

- 主题不适合强 Swiss 网格
- 想让内容更像“私人研究笔记”
- 重点是观点、摘录、判断，而不是数据表格
- 需要更强的阅读停留感

## 视觉语法

1. 背景要像纸，不要像科技海报
2. 主文本要大，允许一句话占一整页
3. 配色优先 `themes.md` 里的 `Kraft Paper`
4. 字色用深棕，不用纯黑
5. 装饰只做三类：
   - 手写下划线
   - 页边批注
   - 细碎纸张噪点
6. 不做重网格，不做发光，不做强 3D

## 版面节奏

- 页眉：来源 / 系列 / 日期
- 主体：摘录、结论或拆解
- 辅助：1 到 3 行说明
- 页脚：`全文 xxxx 字 | 阅读需 x 分钟`

## 贴纸规则

- 可选，不强制
- 如果使用，只放封面页
- 优先放右下角
- 尺寸不超过页面宽度的 `28%`
- 不要压住主摘录文字

## 适配主题

- 财经观察
- 行业复盘
- 阅读摘录
- 产品洞察
- 创作者观点卡

## 不适合

- 强对比科技发布
- 多数据点、多图表的信息图
- 需要大量对齐系统和秩序感的 Swiss 内容
